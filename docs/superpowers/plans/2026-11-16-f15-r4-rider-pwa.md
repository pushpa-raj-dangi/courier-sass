# F15 R4 — Rider PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the rider PWA's run screen, proof-of-delivery flow, scan and profile screens to the approved F15 artboards, backed by one self-scoped read-only backend read (`GET /api/v1/riders/me/today`), without changing the offline outbox.

**Architecture:** Backend adds two narrow batched lookups (shipment task details in one query; a rider's own undeposited COD) on new interfaces implemented by the existing reporting lookup classes, and a small `RiderTodayService` behind the new endpoint. Web adds a pure `runModel.ts`, a `useMyToday` hook keyed under the prefix the outbox already invalidates, a full-height `RiderPodSheet` that replaces `RiderRecordAttemptSheet`, and rewrites the three rider pages.

**Tech Stack:** ASP.NET Core minimal APIs, EF Core (InMemory unit + Postgres lookup/API tests), xUnit; Next.js 14 App Router, TypeScript, TanStack Query v5, Zustand, shadcn/ui, IndexedDB outbox, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-16-f15-r4-rider-pwa-design.md`

## Global Constraints

- No migrations, no new entities, no new write endpoints, no change to existing write behaviour, no new npm or NuGet dependencies.
- `GET /api/v1/riders/me/today` is self-scoped: the rider comes from the JWT user id, never from a request value. No rider for the user → **404**; merchant caller → **403**; unauthenticated → **401**.
- Tenant isolation stays on the global query filters. Every new read uses a fixed number of queries.
- "Today" is the UTC date: `DateOnly.FromDateTime(DateTimeOffset.UtcNow.Date)`.
- The offline outbox (`outboxDb.ts`, `syncManager.ts`, `useRiderPickupScan`, `useCompleteDelivery`, `useRecordFailedAttempt`) keeps its behaviour. The only additions are a derived `pendingItems` list in the outbox status store and UI-side calls to the store's existing `refresh()` after enqueueing.
- Every number shown is server data or outbox state; loading and error states never render `0` — skeletons, `ErrorState`, or "—".
- Unserved data is left off or shown as a disabled control / note saying it needs backend (Fonepay QR, SMS OTP). Never mock values.
- Detail/create views are Sheets driven by Zustand stores (`useRiderAppPanelStore`), never routed pages.
- shadcn/ui components from `@/components/ui/*` only. On-scale type classes only (`text-2xs` … `text-2xl`). Touch targets ≥ 44 px (`h-11` or taller). Status in words, never colour alone.
- Rider-only permission set (for "Open staff console" gating): `delivery.attempt`, `delivery.complete`, `cod.collect`, `shipment.scan`.
- Git tracks the web app as lowercase `src/web` — always `git add src/web/...`. Run npm/npx from `src/web`, dotnet and git from the repo root.
- Web checks: `npm run build`, `npm run lint`, `npm test` pass; `npx tsc --noEmit` 0 errors. Backend: `dotnet build`, listed `dotnet test` projects. Postgres-backed tests need `courier-postgres-1` (5434), `courier-redis-1`, `courier-rabbitmq-1` running (`docker start` them; launch Docker Desktop first if needed). Never `docker compose up`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` verbatim.

### Spec reconciliations (code wins; folded into the tasks)

1. **Batched task lookup on a new interface.** `IShipmentTaskLookupService` has six test fakes; the batched `GetTaskInfosAsync` goes on a new `IShipmentTaskBatchLookupService` implemented by `ShipmentReportingLookupService` (DbContext-only ctor, already Postgres-tested).
2. **Cash lookup on a new interface.** `ICodRiderCashLookupService` is implemented by `CodReportingLookupService`, so no `ICodReportingLookupService` fake changes.
3. **A separate `RiderTodayService`** (not a `RiderService` method) so `RiderService`'s constructor and its seven test call sites stay untouched. It reuses `RiderService.PickTodayRun`, made `internal static`.
4. **Hook key** is `["riders","me","tasks","today","summary"]` instead of `["riders","me","today"]`: the outbox hooks and `syncManager` already invalidate the `["riders","me","tasks","today"]` prefix, so the new read refreshes after every enqueue and drain with no sync-code change.
5. **Outbox status freshness.** `addOutboxItem` does not refresh the status store (only a drain does). Screens that show "waiting to sync" call `useOutboxStatusStore.getState().refresh()` after a successful enqueue.
6. **Header label "Done"** (not "Delivered"): `counts.completed` includes completed pickups.
7. **The failed-attempt form now sends `customerContacted`, `nextAction`, `latitude`, `longitude`** from the form (previously `customerContacted: true` was hard-coded). These are existing fields of the existing write.

## Review Focus

1. **A user signed in without a rider row, or a merchant token** → 404 / 403 from `/riders/me/today`, never another rider's data. Pinned in Task 2 (unit) and Task 3 (API).
2. **Offline enqueue** → the card says "Saved · waiting to sync" immediately and the pickup button is disabled until synced, never "Picked up" while the server hasn't accepted it. Pinned in Task 6 and Task 7.
3. **COD entered short, over, empty or negative** → "Short by Rs X" / "Over by Rs X" in words; empty or negative disables Confirm. Pinned in Task 4 (model) and Task 5 (Sheet).
4. **A scanned AWB already done today or not on the run** → "Already done today" / "isn't on your run today", no write enqueued. Pinned in Task 7.
5. **`me/today` failing while the rider record loads** → `ErrorState` with retry, header counts never `0`. Pinned in Task 6 and Task 8.

```csharp
public record RiderHeldCash(decimal Amount, int ParcelCount, DateTimeOffset OldestCollectedAt);

// F15 R4 rider "my day": the rider's own undeposited COD — the row rule of
// CodService.GetRiderCashAsync (CodCollected and collected by this rider), summed across branches.
// Riders hold no cod.read, so this is only called for the rider resolved from the caller's JWT.

}
```

In `src/Modules/Cod/Application/CodReportingLookupService.cs` change the class declaration to

```csharp
public class CodReportingLookupService : ICodReportingLookupService, ICodRiderCashLookupService
```

and add before the class's closing brace:

```csharp
    public async Task<RiderHeldCash?> GetHeldByRiderAsync(Guid riderId, CancellationToken cancellationToken = default)
    {
        // Bounded by one rider's undeposited parcels, so materialising them is cheap and keeps the
        // CollectedAt ?? CreatedAt fallback identical to GetRiderCashAsync.
        var rows = await _dbContext.Set<CODCollection>().AsNoTracking()
            .Where(c => c.Status == CodCollectionStatus.CodCollected && c.CollectedByRiderId == riderId)
            .Select(c => new { Amount = c.CollectedAmount ?? 0m, At = c.CollectedAt ?? c.CreatedAt })
            .ToListAsync(cancellationToken);
        if (rows.Count == 0)
        {
            return null;
        }
        return new RiderHeldCash(rows.Sum(r => r.Amount), rows.Count, rows.Min(r => r.At));
    }
```

```csharp
using System.Security.Claims;
using Courier.Branches.Application;
using Courier.Cod.Application;
using Courier.Riders.Domain;
using Courier.SharedKernel;
using Courier.Shipments.Application;
using Microsoft.EntityFrameworkCore;

namespace Courier.Riders.Application;

// F15 R4 rider PWA "my day". Self-scoped like GetMyTasksTodayAsync: the rider is resolved from the
// caller's user id, never from a request value, so a rider can only ever read their own day.
// A fixed number of queries: rider, runs, tasks, one batched task-detail read, held cash, branch
// name, vehicle plate. DeliveryRun/DeliveryTask carry no OrganizationId; both are reached only
// through the tenant-filtered Rider row.
public class RiderTodayService
{
    private readonly DbContext _dbContext;
    private readonly IShipmentTaskBatchLookupService _taskLookup;
    private readonly ICodRiderCashLookupService _cashLookup;
    private readonly IBranchLookupService _branchLookup;

    public RiderTodayService(
        DbContext dbContext,
        IShipmentTaskBatchLookupService taskLookup,
        ICodRiderCashLookupService cashLookup,
        IBranchLookupService branchLookup)
    {
        _dbContext = dbContext;
        _taskLookup = taskLookup;
        _cashLookup = cashLookup;
        _branchLookup = branchLookup;
    }

    public async Task<MyTodayResponse?> GetMyTodayAsync(ClaimsPrincipal actingUser, CancellationToken cancellationToken = default)
    {
        var userId = actingUser.GetUserId();
        if (userId is null)
        {
            return null;
        }
        var rider = await _dbContext.Set<Rider>().AsNoTracking().FirstOrDefaultAsync(r => r.UserId == userId, cancellationToken);
        if (rider is null)
        {
            return null;
        }

        var today = DateOnly.FromDateTime(DateTimeOffset.UtcNow.Date);
        var runs = await _dbContext.Set<DeliveryRun>().AsNoTracking()
            .Where(r => r.RiderId == rider.Id && r.Date == today)
            .ToListAsync(cancellationToken);
        var run = runs.Count == 0 ? null : RiderService.PickTodayRun(runs);

        var tasks = new List<MyTodayTask>();
        if (run is not null)
        {
            var runTasks = await _dbContext.Set<DeliveryTask>().AsNoTracking()
                .Where(t => t.DeliveryRunId == run.Id)
                .OrderBy(t => t.Sequence)
                .ToListAsync(cancellationToken);
            if (runTasks.Count > 0)
            {
                var infos = await _taskLookup.GetTaskInfosAsync(runTasks.Select(t => t.ShipmentId).ToHashSet(), cancellationToken);
                foreach (var task in runTasks)
                {
                    // Same rule as GetMyTasksTodayAsync: a task whose shipment can't be read is skipped.
                    if (!infos.TryGetValue(task.ShipmentId, out var info))
                    {
                        continue;
                    }
                    tasks.Add(new MyTodayTask(
                        task.Id, task.ShipmentId, info.Awb, task.Type, task.Sequence, task.Status,
                        info.RecipientName, info.RecipientPhone, info.RecipientAddressLine, info.RecipientWardNumber, info.CodAmount));
                }
            }
        }

        var counts = new MyTodayCounts(
            tasks.Count,
            tasks.Count(t => t.Status == DeliveryTaskStatus.Completed),
            tasks.Count(t => t.Status == DeliveryTaskStatus.Failed));

        var held = await _cashLookup.GetHeldByRiderAsync(rider.Id, cancellationToken);
        var branchNames = await _branchLookup.GetNamesByIdsAsync(new HashSet<Guid> { rider.BaseBranchId }, cancellationToken);
        var plates = await _dbContext.Set<Vehicle>().AsNoTracking()
            .Where(v => v.RiderId == rider.Id)
            .Select(v => v.PlateNumber)
            .ToListAsync(cancellationToken);

        return new MyTodayResponse(
            run is null ? null : new RiderBoardRunSummary(run.Id, run.Status),
            tasks,
            counts,
            held is null ? null : new MyCashHeld(held.Amount, held.ParcelCount, held.OldestCollectedAt),
            branchNames.TryGetValue(rider.BaseBranchId, out var branchName) ? branchName : null,
            plates.OrderBy(p => p, StringComparer.Ordinal).FirstOrDefault());
    }
}
```

```tsx
import Link from "next/link";
import { useRouter } from "next/navigation";
import { Button } from "@/components/ui/button";
import { Skeleton } from "@/components/ui/skeleton";
import { ErrorState } from "@/components/states/ErrorState";
import { useSession } from "@/features/auth/hooks/useSession";
import { formatRs } from "@/features/cod/lib/codFormat";
import { useMyToday } from "@/features/rider-app/hooks/useMyToday";
import { hasStaffPermissions } from "@/features/rider-app/lib/runModel";
import { updateOutboxItem } from "@/features/rider-app/sync/outboxDb";
import { drainOutbox } from "@/features/rider-app/sync/syncManager";
import type { OutboxItem } from "@/features/rider-app/sync/types";
import { useOutboxStatus } from "@/features/rider-app/sync/useOutboxStatus";
import { useMyRider } from "@/features/riders/hooks/useMyRider";
import { riderInitials, roleLabel } from "@/features/riders/lib/riderModel";
import { formatAge } from "@/lib/dates/age";

const CARD = "rounded-xl border border-border bg-card p-4";
const ACTION_LABEL: Record<OutboxItem["action"]["kind"], string> = {
  "pickup-scan": "Pickup",
  "delivery-complete": "Delivery",
  "delivery-fail": "Failed attempt",
};

export default function RiderProfilePage() {
  const { data: rider, isLoading: riderLoading } = useMyRider();
  const today = useMyToday(!!rider);
  const { data: session } = useSession();
  const { pendingCount, stuckItems, refresh } = useOutboxStatus();
  const router = useRouter();

  async function handleLogout() {
    await fetch("/api/auth/logout", { method: "POST" });
    router.push("/login");
  }

  async function handleRetry(itemId: string) {
    // Flip the item back to "pending" and kick a drain. A still-permanent 4xx marks it "stuck"
    // again — this only guarantees a rejected action always has a way back (CLAUDE.md §39).
    await updateOutboxItem(itemId, { status: "pending", lastError: undefined });
    await refresh();
    void drainOutbox();
  }

  function awbFor(item: OutboxItem): string {
    const fromRun = today.data?.tasks.find((t) => t.shipmentId === item.action.shipmentId)?.awb;
    if (fromRun) return fromRun;
    if (item.action.kind === "pickup-scan") return item.action.awb;
    return item.action.shipmentId.slice(0, 8);
  }

  const name = session?.fullName ?? "";
  const data = today.data;

  return (
    <div className="flex min-h-full flex-col">
      <header className="flex items-center gap-3.5 bg-sidebar px-4 pb-4 pt-5 text-sidebar-foreground">
        <span className="flex h-12 w-12 shrink-0 items-center justify-center rounded-full bg-sidebar-primary text-base font-semibold text-sidebar-primary-foreground" aria-hidden="true">
          {name ? riderInitials(name) : "?"}
        </span>
        <div className="space-y-0.5">
          <h1 className="font-display text-xl font-semibold">{name || "Rider"}</h1>
          <p className="text-xs text-sidebar-muted">
            {rider ? `${roleLabel(rider.roleType)}${data?.branchName ? ` · ${data.branchName}` : ""}` : "—"}
          </p>
        </div>
      </header>

      <div className="flex-1 space-y-3 px-4 pb-24 pt-3">
        {today.isError ? (
          <ErrorState title="Couldn't load today" description="Check your connection and try again." onRetry={() => today.refetch()} />
        ) : (
          <section aria-label="Today" className={`${CARD} grid grid-cols-2 gap-3`}>
            {riderLoading || today.isLoading || !data ? (
              <Skeleton role="status" aria-label="Loading today" className="col-span-2 h-16 w-full" />
            ) : (
              <>
                <div className="space-y-1">
                  <p className="font-mono text-2xs uppercase tracking-[0.1em] text-muted-foreground">Today</p>
                  {data.run ? (
                    <>
                      <p className="text-2xl font-semibold tabular-nums">
                        {data.counts.completed}
                        <span className="ml-1 text-sm font-normal text-muted-foreground">{`of ${data.counts.assigned} done`}</span>
                      </p>
                      {data.counts.failed > 0 && <p className="text-xs font-semibold text-destructive">{`${data.counts.failed} failed`}</p>}
                    </>
                  ) : (
                    <p className="text-sm text-muted-foreground">No run today</p>
                  )}
                </div>
                <div className="space-y-1">
                  <p className="font-mono text-2xs uppercase tracking-[0.1em] text-muted-foreground">Cash in hand</p>
                  {data.cash ? (
                    <>
                      <p className="text-2xl font-semibold tabular-nums">{formatRs(data.cash.amount)}</p>
                      <p className="text-xs text-muted-foreground">{`${data.cash.parcelCount} COD ${data.cash.parcelCount === 1 ? "parcel" : "parcels"} · oldest ${formatAge(data.cash.oldestCollectedAt)}`}</p>
                    </>
                  ) : (
                    <p className="text-sm text-muted-foreground">No cash held</p>
                  )}
                </div>
                {data.cash && (
                  <p className="col-span-2 text-xs text-foreground">
                    {`Hand cash over at the ${data.branchName ?? "branch"}${data.branchName ? " branch" : ""} COD counter before you sign off.`}
                  </p>
                )}
              </>
            )}
          </section>
        )}

        {stuckItems.length > 0 && (
          <section aria-label="Needs review" className="space-y-2.5 rounded-xl border-2 border-destructive bg-card p-4">
            <div className="flex items-baseline justify-between">
              <h2 className="text-base font-semibold text-destructive">{`Needs review · ${stuckItems.length}`}</h2>
              <span className="text-xs text-muted-foreground">Not sent to the office</span>
            </div>
            {stuckItems.map((item) => (
              <div key={item.id} className="space-y-1.5 rounded-lg border border-destructive/40 p-3">
                <p className="text-sm font-semibold">
                  {`${ACTION_LABEL[item.action.kind]} · `}
                  <span className="font-mono font-medium">{awbFor(item)}</span>
                </p>
                {item.lastError && <p className="text-sm text-foreground">{item.lastError}</p>}
                <Button type="button" variant="outline" className="h-11" onClick={() => void handleRetry(item.id)}>
                  Try again
                </Button>
              </div>
            ))}
          </section>
        )}

        <section aria-label="Sync" className={`${CARD} space-y-2`}>
          <div className="flex items-center justify-between">
            <h2 className="text-sm font-semibold">Sync</h2>
            <span className={pendingCount > 0 ? "text-xs font-semibold text-status-ndr" : "text-xs font-semibold text-status-delivered"}>

          <Button type="button" variant="outline" className="h-11" onClick={() => void drainOutbox()}>
            Send now
          </Button>
        </section>

        <section aria-label="Details" className={CARD}>
          <dl className="grid grid-cols-2 gap-3">
            <div className="space-y-0.5">
              <dt className="text-2xs text-muted-foreground">Base branch</dt>
              <dd className="text-sm font-medium">{data?.branchName ?? "—"}</dd>
            </div>
            <div className="space-y-0.5">
              <dt className="text-2xs text-muted-foreground">Vehicle</dt>
              <dd className="font-mono text-sm font-medium">{data ? data.vehiclePlate ?? "No vehicle" : "—"}</dd>
            </div>
            <div className="space-y-0.5">
              <dt className="text-2xs text-muted-foreground">Licence</dt>
              <dd className="text-sm font-medium">{rider?.licenseNumber ?? "—"}</dd>
            </div>
            <div className="space-y-0.5">
              <dt className="text-2xs text-muted-foreground">Location</dt>
              <dd className="text-sm font-medium">Shared while open</dd>
            </div>
          </dl>
        </section>

        <div className="space-y-2 pt-1">
          {session && hasStaffPermissions(session.permissions) && (
            <Button asChild variant="outline" size="lg" className="h-12 w-full">
              <Link href="/dashboard">Open staff console</Link>
            </Button>
          )}
          <Button type="button" variant="outline" size="lg" className="h-12 w-full text-destructive" onClick={handleLogout}>
            Sign out
          </Button>
        </div>
      </div>
    </div>
  );
}
```

````markdown
### 6.8 Rider "my day" (rider PWA)

`GET /api/v1/riders/me/today` — authenticated staff; self-scoped (the rider is resolved from the
caller's user id). `404` when the user has no rider record, `403` for merchant tokens.

```json
{ "run": { "id": "…", "status": "Active" },
  "tasks": [{ "taskId": "…", "shipmentId": "…", "awb": "NX-260930-00148", "type": "Delivery",
    "sequence": 15, "status": "Pending", "recipientName": "…", "recipientPhone": "…",
    "recipientAddressLine": "…", "recipientWardNumber": 4, "codAmount": 2500 }],
  "counts": { "assigned": 32, "completed": 14, "failed": 2 },
  "cash": { "amount": 18450, "parcelCount": 9, "oldestCollectedAt": "…" },
  "branchName": "Lalitpur", "vehiclePlate": "BA 2 PA 1111" }
```

- `tasks` holds every status of today's run (UTC date), ordered by `sequence`; shipment details come
  from one batched lookup. `run` is null and `tasks` empty when the rider has no run today.
- `cash` is the rider's own undeposited COD (`CodCollected` rows collected by the rider, all branches),
  or null. `GET /riders/me/tasks/today` (pending tasks only) is unchanged.
````
